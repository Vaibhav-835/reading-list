# Little Library 📚

A simple, minimal reading-list web app for keeping track of the books
you want to read and the books you have finished.

Built with plain **HTML, CSS, and JavaScript**. No frameworks, package
installation, or build tools required.

## ✨ Features

-   **Add books** --- save a book title and optionally include its
    author.
-   **Track reading status** --- mark books as read or unread.
-   **Filter your list** --- view all books, books to read, or completed
    books.
-   **Reading progress** --- see how many books you've completed and
    your progress percentage.
-   **Delete books** --- remove individual books from your shelf.
-   **Clear completed** --- remove all books marked as read.
-   **Persistent storage** --- your list is saved in the browser with
    `localStorage`.
-   **Responsive design** --- works on desktop and mobile screens.

## 🎨 Design

Little Library uses a calm, minimal visual style with a sage-green and
cream color palette, simple book-inspired details, and a responsive
layout.

## 🚀 Getting Started

### Run locally

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in a modern web browser.

That's it! There are no dependencies to install and no build command to
run.

### Clone the repository

``` bash
git clone https://github.com/YOUR-USERNAME/little-library.git
cd little-library
```

Then open `index.html` in your browser.

> If your downloaded project file is named
> `little-library-reading-list.html`, rename it to `index.html` before
> publishing it as the main GitHub Pages page.

## 💾 Data Storage

Books are stored in the browser's `localStorage` under the key
`little-library-books-v1`.

-   Your list remains available when you reopen the app in the same
    browser.
-   Data is stored locally in that browser, not in a cloud database.
-   Clearing browser site data or using a different browser/device may
    remove or hide your saved list.

## 🌐 Deploy with GitHub Pages

1.  Push the project to a GitHub repository.
2.  Make sure the main HTML file is named `index.html` and is in the
    repository root.
3.  Open the repository's **Settings → Pages**.
4.  Under **Build and deployment**, choose **Deploy from a branch**.
5.  Select your branch (usually `main`) and the `/ (root)` folder, then
    save.
6.  After GitHub Pages finishes deploying, open the published URL shown
    in the Pages settings.
